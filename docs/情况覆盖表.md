# 情况覆盖表

> 版本：v0.1（2026-11-18）。
> Nuo 要学会应付的各种情况。生成训练数据、出考卷，都按这张表挑组合，保证每种情况都有样本，不会全是「初见打招呼」。
> 每条样本从下面 7 个方面**各挑一项**组合，不是把所有组合全做一遍。⭐ = 重点，多做。

## 1. 目的：这段话要办成什么

| # | 目的 | 合格标准 |
| --- | --- | --- |
| 1 | 给消息 / 指路 | 消息说全、说对，用这个人的口气 |
| 2 | 推对方去做某事 | 推的理由像这个人（师傅骂着推，阿姨唠叨着推） |
| 3 | 拒绝 | 拒绝的理由和方式像这个人，不是一句「不行」 |
| 4 | 讨价还价 / 交易 | 守住价钱和底线，有来有回 |
| 5 | 套对方的话 | 说话人自己在打听，问得自然，不像审问 |
| 6 | 安慰 / 劝 | 用这个人会用的方式（嘴损的人安慰也是损的） |
| 7 | 警告 / 威胁 | 分寸符合身份和关系 |
| 8 | 认错 / 推脱 | 好面子的认错别扭，狡猾的会推脱 |
| 9 | 闲聊 / 气氛 | 没有要办的事，只让人物活起来 |
| 10 | 告别 / 打发人走 | 收得住，不拖泥带水 |

## 2. 对方出的难题（主要用于「接一句」）

| # | 难题 | 合格标准 |
| --- | --- | --- |
| a | 没有难题 | — |
| b | ⭐ 问到不能说的事 | 不说漏；按性格应付（撒谎 / 岔开 / 发火）；**不能**说「这个我不能告诉你」这种机器腔 |
| c | ⭐ 问世界外的事（「你是 AI 吗」「这游戏怎么玩」） | 不出戏，按【世界】里「世界外的事」处理 |
| d | 被冒犯、被骂 | 反应符合性格和关系（忍着 / 回骂 / 冷笑） |
| e | 被夸、被讨好 | 符合性格（不夸人的人被夸也不领情） |
| f | 求情、哀求 | 按性格心软或不心软 |
| g | 撒谎、说胡话 | 精明的能识破，老实的会信 |
| h | 要求做违背性格的事 | 不照做，或很别扭地照做 |
| i | 无意义的输入（乱码、「啊啊啊」） | 按性格当成怪事，不卡住 |

## 3. 关系（说话人怎么看对方）

陌生人 / 点头之交 / 熟人 / 亲近（家人、师徒）/ 有过节 / 对方地位比他高 / 对方地位比他低

## 4. 状态

- 初见 / 再见
- 有没有「已发生的事」（态度因此变了）
- 白天 / 晚上（按世界的说法）
- 有没有别人在场

## 5. 双方的「眼下」

**对方的样子**（只写说话人看得见的）：

| 取值 | 例子 |
| --- | --- |
| 平常 | 不写 |
| 受伤 / 狼狈 | 手上缠着布、衣服破了、一身泥 |
| 慌张 / 着急 | 跑得满头汗、东张西望 |
| 气冲冲 | 黑着脸、拍桌子 |
| 喝醉 | 满身酒气、站不稳 |
| 打扮反常 | 穿官服、一身贵气、一身破烂 |
| 拿着显眼的东西 | 刀、礼物、钱袋、外卖 |

**说话人自己**：平常 / 正忙着干活 / 困了、累了 / 喝醉 / 受了伤 / 正在吃饭

合格标准：反应符合性格，**不一定说出口**。要有一部分样本是看见了却不提，或只拐着弯带一句，不能每次都点评。

## 6. 格式变化（学会守规矩）

- 用法：写整段 / 接一句
- 句数：1–2 / 2–4 / 3–6
- 每句字数上限：20 / 40 / 60
- 表情清单：每个世界不同
- 动作：写 / 不写
- 谁能开口：只有说话人 / 对方也能接一句

## 7. 世界（证明不绑游戏）

| 世界 | 说话 |
| --- | --- |
| 古风 | 半白话（另编世界，不用任何游戏的私有设定） |
| 现代 | 普通话口语，市井味或职场味 |
| 西式奇幻 | 翻译腔、骑士 / 法师 / 酒馆 |
| 科幻 | 飞船、殖民地、机器人 |

## 所有样本都要满足

不出戏；没有禁用词；不说漏秘密；句数、字数不超；不写旁白；不替别人说话（除非【要求】允许）；口气像这个人；要办成的事确实办成了。

## 试跑（第一批）抽样（2026-11-18 定）

- 5 个练习角色，每人放进 1 个世界（4 个世界至少各占 1 个）。
- 共 40 条：写整段 20 条、接一句 20 条；接一句里难题 b、c 各至少 5 条；双方「眼下」不是「平常」的至少 10 条。
- 练习角色的档案、每条的场景卡和台词都由 DeepSeek 写；Claude 只按本表挑组合、写给 DeepSeek 的说明、判断留不留。
