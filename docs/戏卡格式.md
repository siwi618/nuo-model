# 戏卡格式

> 版本：v0.2（2026-11-18：【说话人】【对方】各加一行「眼下」）。
> 一张**戏卡**进去，几句**台词**出来。戏卡说清楚「谁、在什么世界、对谁、在哪、刚说了什么、要办成什么、有什么限制」，Nuo 用这个人的性格和口气把话说出来。

## 一、总览

戏卡固定分 **7 块**，顺序不变（小模型靠固定顺序认位置）：

| # | 块 | 写什么 |
| --- | --- | --- |
| 1 | 【世界】 | 这个世界的人怎么说话：腔调、称呼、本场用到的词、不能出现的词、被问到世界外的事怎么办 |
| 2 | 【说话人】 | 这个人是谁：一句话、性格、说话方式、例句、想要 / 怕、知道的事、**不能说的事**；眼下在干什么、身体怎样 |
| 3 | 【对方】 | 听话的人是谁 + **说话人怎么看他**（只写单向）+ 他眼下看上去什么样；有别人在场也写上 |
| 4 | 【场景】 | 地点时间、前情、**已经发生的事**（由游戏先算好，见第四节） |
| 5 | 【前文】 | 刚才说过的几句，最多 10 句；开场写「无」 |
| 6 | 【目的】 | **要办成**什么、说话人**心里想的**、这段**别说漏**什么 |
| 7 | 【要求】 | 用法、句数、每句最多几个字、能用的表情、能不能写动作、谁能开口 |

整张卡建议 **≤ 1500 字**。小模型读的东西越短越准。

**输出**只有台词，一句一行：

```
名字[表情]: 话
```

- 表情是「平常」时不写方括号：`名字: 话`。
- 表情只能用【要求】里列出的。
- 【要求】写了「动作：可以写」时，动作放在话的最前面，用全角括号：`名字[表情]: （低头擦鞋）话`。没写就不能有动作。
- 不写旁白、不写选项、不写分支，也不写「给钱 / 接活」这类事——这些都归游戏管，Nuo 只管说话。

## 二、每块的写法

> **必** = 每次都要有；**挑** = 只放和这场有关的，没关系就不写这一行；**可** = 有就写。

### 1【世界】

```
【世界】
腔调：……
称呼：……
本场的词：词（解释）、词（解释）
不能出现：……
世界外的事：……
```

| 行 | | 写什么 |
| --- | --- | --- |
| 腔调 | 必 | 总体说话风格，按身份有分层就写清楚这个人属于哪层 |
| 称呼 | 挑 | 这场会用到的叫法 |
| 本场的词 | 挑 | 这场会用到的世界里的词，括号里一句解释；同一样东西不同人叫法不同，写说话人那种叫法 |
| 不能出现 | 必 | 现代词 / 现实名字 / 游戏术语等，按世界定 |
| 世界外的事 | 必 | 人物不知道自己在故事里。被问「你是不是 AI」「这游戏怎么玩」时怎么处理（一般：按性格当成怪话岔开） |

### 2【说话人】

```
【说话人】名字
一句话：……
性格：……
说话：……
例句：「……」「……」「……」
想要：……
怕：……
知道：……
不能说：……；……
眼下：……
```

| 行 | | 写什么 |
| --- | --- | --- |
| 一句话 | 必 | 这人是谁 |
| 性格 | 必 | 三四个词或短句 |
| 说话 | 必 | 句子长短、口头禅、怎么称呼别人 |
| 例句 | 必 | 3–5 句，最能代表他口气的话；**模型主要靠这个学口气** |
| 想要 / 怕 | 挑 | 和这场有关才写 |
| 知道 | 挑 | 说话人此刻「提得到的」具体事实：职业流程、价目、菜单、作息、地点、熟人习惯、最近发生的事。**接游戏时由游戏代码按人物身份填**（常设素材 + 游戏里已发生的事），可以写 5–8 条、大半和这场无关；模型的规矩是具体细节（人名、地名、数目、约定）只从卡里拿，卡里没有就说得笼统。不要把「要办成」的内容写进来（2026-11-25 小试：加素材后和 9B 老师的差距 −0.67 → −0.11；11-26 定不另加栏，栏名不变，模型只见过「知道」） |
| 不能说 | 必 | **全部写上**，哪怕看着和这场无关（「接一句」时对方随时可能问到）；没有就写「无」 |
| 眼下 | 可 | 说话人此刻的身体状态和手上的事：正忙着干活、困了、喝醉了、受了伤。心里的想法不写这里，写【目的】的「心里想的」 |

外貌一般不放（台词用不上），除非这场有人会提到他的长相。

### 3【对方】

```
【对方】名字
是谁：……
<说话人>怎么看他：……
眼下：……
在场：名字（<说话人>怎么看他）；……
```

| 行 | | 写什么 |
| --- | --- | --- |
| 是谁 | 必 | 一句话 |
| 怎么看他 | 必 | 只写说话人的看法（单向）。对方怎么看说话人不写——那是对方开口时的事 |
| 眼下 | 可 | 对方此刻**看得见**的样子：受伤、湿透、慌张、喝醉、打扮反常、手里拿着显眼的东西。**只写说话人看得见的**，不写对方心里想什么。说话人不一定要点评它，反应符合性格就行 |
| 在场 | 可 | 旁边还有谁，说话人怎么看他们 |

### 4【场景】

```
【场景】
地点时间：……
前情：……
已发生的事：……。→ ……
```

| 行 | | 写什么 |
| --- | --- | --- |
| 地点时间 | 必 | 在哪、白天还是晚上（按世界的说法） |
| 前情 | 可 | 刚刚发生了什么 |
| 已发生的事 | 可 | 由游戏先查好、翻成大白话的事实；后面可以跟「→ 说话人因此怎样」。见第四节 |

### 5【前文】

```
【前文】
名字: 话
名字[表情]: 话
```

- 和输出同一种写法，最多 10 句，从旧到新。
- 开场写 `【前文】无`。

### 6【目的】

```
【目的】
要办成：……
心里想的：……
别说漏：……
```

| 行 | | 写什么 |
| --- | --- | --- |
| 要办成 | 必 | 这段话**必须**做到的事：给什么消息、推对方去哪、拒绝什么。由游戏定 |
| 心里想的 | 可 | 说话人自己没说出口的想法（潜台词），比如「担心他，但不想让他看出来」。好演员味儿靠这一行 |
| 别说漏 | 可 | 这段**特别容易**说漏的事（从「不能说」里挑出来强调，也可以是只在这场要藏的事） |

### 7【要求】

```
【要求】
用法：写整段
句数：2–4
每句最多：40 字
表情：平常、生气、难过、惊讶
动作：不写
谁能开口：名字
```

| 行 | 写什么 |
| --- | --- |
| 用法 | **写整段**（写剧本时用，一段完整的话）或 **接一句**（对方刚说完，回 1–2 句） |
| 句数 | 范围，比如 2–4；接一句一般 1–2 |
| 每句最多 | 字数上限，按各游戏的对话框定 |
| 表情 | 这个游戏有的表情，逗号隔开 |
| 动作 | 不写 / 可以写 |
| 谁能开口 | 默认只有说话人；要让对方或旁人也说，就列上名字 |

## 三、两种用法

| | 写整段 | 接一句 |
| --- | --- | --- |
| 什么时候 | 写剧本、台词本时 | 以后游戏里对方随口说话时 |
| 【前文】 | 一般是「无」或前面一段 | 最后一句是对方刚说的话 |
| 【要求】句数 | 2–6 | 1–2 |

同一个格式，同一个模型两种都学。

## 四、「会变的地方」：游戏先算好再写进卡里

人物档案里常有「如果发生了某事，态度就变」这种写法。**Nuo 不自己判断条件**，由游戏代码先查自己的记录，只把**成立的**那条翻成大白话放进【场景】的「已发生的事」。不成立的根本不出现在卡里。

例：档案里写着

```
如果 帮过忙   → 格外热情
如果 欠钱没还 → 冷淡，催债
```

游戏记录里「帮过忙 = 有」「欠钱没还 = 没有」，卡里就只写：

```
已发生的事：小林上周帮她搬过煤气罐。→ 梅姨对他格外热情。
```

秘密也一样：某个秘密在剧情里已经揭开了，游戏就把它从【说话人】的「不能说」里删掉，人物才能谈它。

为了能算，档案里的条件要用游戏记录里的同一个名字来写。

## 五、输出检查（以后由代码做）

模型写完，游戏或数据脚本先查一遍，不合格就重写或退回手写台词：

1. 每行都能读成 `名字[表情]: 话`；
2. 句数在范围内，每句不超字数；
3. 表情在清单里，开口的人在「谁能开口」里；
4. 没有「不能出现」的词；
5. 没有说出「不能说」「别说漏」里的东西（先按关键词查）。

## 六、机器格式（一行一条样本）

人看的是上面的卡片；仓库里同一份内容另存成 **JSON Lines**（`.jsonl`，一行一个 JSON），训练工具都认这种格式。卡片和 JSON 一一对应，用 `scripts/render_card.py` 互相转（目前只做了 JSON → 卡片）。

```json
{
  "id": "例子-梅姨-整段-001",
  "source": "claude",
  "use": "scene",
  "card": {
    "world":    {"tone": "", "address": "", "terms": [""], "banned": "", "offstage": ""},
    "speaker":  {"name": "", "summary": "", "personality": "", "speech": "", "examples": [""],
                 "wants": "", "fears": "", "knows": "", "secrets": [""], "now": ""},
    "listener": {"name": "", "summary": "", "view": "", "now": "", "others": [{"name": "", "view": ""}]},
    "scene":    {"place_time": "", "backstory": "", "happened": [""]},
    "history":  [{"name": "", "emotion": "", "text": ""}],
    "goal":     {"must": "", "inner": "", "dont_leak": [""]},
    "rules":    {"use": "scene", "lines": [2, 4], "max_chars": 40,
                 "emotions": ["平常"], "actions": false, "speakers": [""]}
  },
  "output": [{"name": "", "emotion": "", "text": ""}],
  "meta": {"world": "", "date": "", "generator": "", "kept_by": "", "notes": ""}
}
```

| 字段 | 对应卡片 |
| --- | --- |
| `world` | 【世界】：腔调 / 称呼 / 本场的词 / 不能出现 / 世界外的事 |
| `speaker` | 【说话人】；`secrets` = 不能说；`now` = 眼下 |
| `listener` | 【对方】；`view` = 说话人怎么看他；`now` = 眼下；`others` = 在场 |
| `scene` | 【场景】；`happened` = 已发生的事 |
| `history` | 【前文】；`emotion` 为空 = 平常 |
| `goal` | 【目的】：`must` 要办成 / `inner` 心里想的 / `dont_leak` 别说漏 |
| `rules` | 【要求】；`use`：`scene` = 写整段，`reply` = 接一句 |
| `output` | 输出的台词 |
| 空字符串 / 空列表 | 这一行不写 |

### `source`：这条台词是谁写的（必填）

| 值 | 意思 | 能不能拿来训练 |
| --- | --- | --- |
| `deepseek` | DeepSeek 写的 | 能（DeepSeek 用户协议 / 开放平台服务协议 §4.2 允许训练其他模型） |
| `human` | 人手写的 | 能 |
| `human_edited` | 人改过的 DeepSeek 稿 | 能 |
| `claude` | Claude 写的（比如本仓库的示例） | **不能**（Anthropic 使用政策不允许未经许可拿 Claude 的输出训练模型） |

训练脚本只读 `deepseek` / `human` / `human_edited`。`meta.kept_by` 记谁决定留下这条（只决定留 / 不留，判断本身不进训练数据）。

## 七、文件放哪

- `docs/`：说明文档（这篇）。
- `examples/`：示例卡片和对应的 `.jsonl`，全是自编的练习角色，`source` 都是 `claude`，**不进训练**。
- `data/`：真正的训练数据，**不进 git**（见 `.gitignore`）。各游戏自己的设定和台词留在各自的仓库里。
- 以后公开数据集时，要标明台词由 AI 生成（DeepSeek 协议 §3.1 / §3.7）。
