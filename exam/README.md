# Nuo 考卷 v1

24 张戏卡，**永远不拿来训练**，只用来检查训练后的 Nuo。只有题目（戏卡），没有标准答案。

| 组 | 张数 | 考什么 |
| --- | --- | --- |
| S | 8 | 训练里出现过的角色，换新场景：记不记得这个人 |
| N | 8 | 训练里没出现过的新角色：能不能读档案就演出来 |
| W | 8 | 训练里没有的新世界（武侠、民国、太空殖民、民间恐怖、刑侦、推理）：是不是真的不绑世界 |

- `考卷.jsonl`：机器读的（格式见 `docs/戏卡格式.md`）；`考卷-看.txt`：人看的。
- `make_exam.py`：生成脚本。
- 民间恐怖、推理两类整类留给考卷，训练完全不用；另外四类训练可用，但要换别的具体世界。
- 训练前必须跑 `python3 scripts/exam_guard.py <训练数据.jsonl>`，不通过不许训。

**AI 生成内容说明**：本考卷由 AI 生成——戏卡大部分由 Claude 编写；S 组的人物档案和 S、N 组用到的世界设定由 DeepSeek 生成。
