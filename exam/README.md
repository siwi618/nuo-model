# Nuo 考卷 v2

**永远不拿来训练**，只用来检查训练后的 Nuo。只有题目（戏卡），没有标准答案。

- **公开卷** `考卷.jsonl`：60 张，按难度分三档，分数按 简单 40% / 中等 40% / 困难 20% 加权，各档也分开报。
  - 简单 24：一件事、一个清楚的要求。
  - 中等 24：两三样要兼顾（守秘 / 对方状态 / 动作 / 出戏 / 有人在场）。
  - 困难 12：多个约束互相拉扯：被当面施压还要守秘、要精确照抄字和数字、长前文不能自相矛盾、整段层层推进不重复、话说给一个人听又不能让旁人听懂。
- **隐藏卷** `隐藏卷.jsonl`：18 张（7 / 7 / 4），平时不看，只在最后拍板时用一次，防止我们反复挑检查点、调参数，最后选出来的只是「刚好擅长这几张」的版本。
- 分组：S = 训练里出现过的角色换新场景；N = 训练里没出现过的新角色；W = 训练里没有的新世界（武侠、民国、太空殖民、民间恐怖、刑侦、推理、海岛渔村、蒸汽朋克、宫廷）。
- v1 的 24 张（2026-11-18）全部保留并分了档，见 `make_exam.py` 的 `V1_TIER`；v2 新卡在 `v2_easy.py`、`v2_mid.py`、`v2_hard.py`。
- `考卷-看.txt`：公开卷人看的版本。`make_exam.py`：生成脚本（`python3 exam/make_exam.py`）。
- **考点** `考点.json`（2026-11-20）：公开卷 60 张各考哪些缺陷（标签 + 一句「注意」），给审稿的人看、给 `exam_stats.py` 按考点算问题率用。只是标注，考卷本身一字不改。最关键的一条是「心里话·要藏」和「心里话·可说」：可说 = 心里想的正是办事的自然理由，说出来也正常。
- **专项卷** `专项-心里话.jsonl`（2026-11-20，15 张，`special_inner.py` 生成，人看 `专项-心里话-看.txt`）：每张都逼说话人谈到「心里想的」旁边的话题，心里想的说出来会伤人、露怯或坏事、且不是办事的理由；不放「别说漏」。为什么要有：弱版本「要办成」办得少，「心里话说出口」就冒不出来（隐形缺陷），专项卷让每个版本都站到同一个犯错的边上。单独算分，不混进公开卷。

## 怎么考

```
.venv/bin/python scripts/run_exam.py 模型 输出前缀 [--adapter 适配器目录]     # 默认 3 个种子、带随机 + 重复惩罚
.venv/bin/python scripts/exam_stats.py 基准=输出前缀 新版=输出前缀            # 分档、加权、95% 区间、逐卡配对
```
同一张卡考 3 次（换随机种子），各版本用同一组种子，逐卡配对比较。2026-11-19 发现：24 张、贪心解码只考一次，两个理论上等价的版本全合规数也能差 4 张，见仓库根目录 `lab_note.md`。

## 守卫

- 民间恐怖、推理两类整类留给考卷，训练完全不用；其余新世界训练可用，但要换别的具体世界。
- 训练前必须跑 `python3 scripts/exam_guard.py <训练数据.jsonl> --exam exam/考卷.jsonl`，隐藏卷也要跑一遍（`--exam exam/隐藏卷.jsonl`），不通过不许训；专项卷同样（`--exam exam/专项-心里话.jsonl`）。
